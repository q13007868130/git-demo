# PCSX2 Modern Netplay Port

This repository is being used as the build/control repository for a modern PCSX2 netplay port.

Targets:
- Upstream base: latest PCSX2 master
- Netplay reference: SmileTheory/pcsx2 (PCSX2 1.5-era Online Plus) and alexsharoff/pcsx2-online
- First milestone: Windows x64 build + deterministic two-player delay-based netplay input exchange
- Initial compatibility target: local multiplayer titles such as Tekken 5

This repository does not contain BIOS files or game images.
